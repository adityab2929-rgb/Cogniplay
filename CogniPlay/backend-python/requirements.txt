# ---------------------------------------------------------------------------
# OPTIONAL -- heavy, service degrades gracefully without these
# ---------------------------------------------------------------------------
# Everything below is wrapped in try/except ImportError with a working
# NumPy-only fallback. Together they are roughly 2.5 GB installed, so skip
# them unless you specifically need the feature listed.
#
# Check what is actually loaded at runtime with:  GET /health
#
# torch          -- enables the real CNN / LSTM networks. Note that NO trained
#                   weights ship with this project, so installing torch alone
#                   changes nothing: the fusion model still uses the clinical
#                   heuristics until a .pt file is placed in saved_models/.
#                   Without torch: NumPy fallback models, same interface.
# scikit-learn   -- required by shap.
# pandas         -- required by shap.
# shap           -- KernelExplainer attributions.
#                   Without it: analytic weight x value attribution, which for
#                   this additive model is the same answer in closed form.
# opencv-python  -- fastest PNG encoding for the heatmap.
#                   Without it: Pillow, then a stdlib zlib PNG writer.
# reportlab      -- typeset parent PDF report.
#                   Without it: a plain but valid stdlib-generated PDF.
# matplotlib     -- not required by the service; useful for offline analysis
#                   and for plotting during model development.
